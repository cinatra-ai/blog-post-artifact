# Blog Post

A finished, publish-ready blog article in Markdown. Blog Posts cover both articles generated by Cinatra's blog pipeline and posts uploaded from an existing CMS or another writing tool, so the same library surface holds new drafts and the historical archive side by side.

Install this artifact via the Cinatra marketplace. Once installed, upload a Markdown file (MIME type `text/markdown`) to the library — the built-in `blog-post-matcher` skill classifies the document automatically and requires a confidence score of at least 0.7 to accept it as a Blog Post. Strong signals include front matter, an H1 or implicit title, structured narrative sections, and 300 or more words; any combination missing one of these may still reach the 0.70–0.84 range. Outlines, rough drafts with TODO markers, social posts, and other unfinished documents are intentionally rejected with `matches:false`. For local development, run `node extension-kind-gate.mjs` at the repo root and confirm zero errors before submitting to the marketplace.

## Works with

- Blog Draft Writer agent
- Blog Pipeline agent
- Blog Image Prompt agent
- WordPress Publish agent
- LinkedIn Publish agent

## Capabilities

- Hold a complete article body — title, sections, and embedded media
- Reuse the same draft across multiple publish targets
- Hand a finished post to image-prompting and publishing agents
- Edit, preview, and reclassify articles directly from the library
